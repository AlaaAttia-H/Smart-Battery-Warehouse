# NTFY App Setup

Follow the steps below to receive notifications from this project.

## 1. Install the ntfy App

Download and install the **ntfy** app on your device:

- **Android:** Google Play Store
- **iOS:** Apple App Store

## 2. Subscribe to the Topic

1. Open the **ntfy** app.
2. Tap the **+** button to add a new subscription.
3. Enter the following topic:

   ```
   smartwarehouse-group29-alerts
   ```

4. Tap **Subscribe**.

## 3. Enable Notifications

Allow the app to send notifications when prompted. If notifications are disabled, enable them in your device's notification settings.

## 4. You're Ready!

You will now receive all notifications sent to the following topic:

`smartwarehouse-group29-alerts`
